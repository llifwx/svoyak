# Своя игра

Браузерная викторина в духе «Своей игры» для компании друзей. Ведущий открывает игру на ноутбуке (можно вывести на телевизор), игроки жмут кнопку со своих телефонов. Без сервера, сборки и регистрации: три статических файла.

## Возможности

- **Редактор вопросов:** раунды, темы, цены. У вопроса и ответа может быть текст, картинка и звук.
- **Игровое табло** на весь экран. Счёт игроков внизу, у лидера корона, счёт можно поправить вручную.
- **Экран вопроса** на весь экран. Звук вопроса играет сам. По кнопке «Показать ответ» картинка и звук вопроса меняются на картинку и звук ответа.
- **Специальные вопросы:**
  - Кот в мешке: ведущий отдаёт вопрос одному игроку.
  - Двойная ставка: вопрос стоит ×2, и в плюс, и в минус.
  - Без риска: за неверный ответ баллы не снимаются.
- **Модификаторы вместо вопроса:**
  - Плюс на минус: у выбранного игрока меняется знак счёта.
  - Обмен счётом: два игрока меняются счётом.
  - Подарок: игрок получает цену клетки.
- **Финал:** игроки делают ставки от 0 до своего счёта.
- **Кнопки на телефонах:** игроки сканируют QR-код и жмут большую кнопку. Кто нажал первым, того игра подсвечивает и подаёт звуковой сигнал.
- **Пак вопросов в файле:** его можно сохранить в JSON и загрузить обратно, чтобы перенести на другой компьютер или поделиться.

## Как запустить

**Локально.** Откройте `index.html` в браузере. Работает всё, кроме кнопок на телефонах.

**На хостинге.** Нужно для телефонов: им требуется ссылка с https. Подойдёт любой статический хостинг, например Render (Static Site), GitHub Pages или Netlify:

- корень публикации — корень репозитория;
- команда сборки не нужна.

## Как играть

1. **Пак.** В меню нажмите «Редактор вопросов» и заполните пак. Он сохраняется в браузере автоматически.
2. **Игроки.** Нажмите «Начать игру», впишите игроков и нажмите «Начать».
3. **Телефоны (по желанию).** Нажмите «Телефоны» в шапке. Игроки сканируют QR-код и выбирают себя из списка.
4. **Вопрос.** Нажмите на клетку. Внизу экрана отмечайте, кто ответил верно и кто неверно. Если игрок ответил неверно, кнопки на телефонах снова открываются для остальных.
5. **Дальше.** «Следующий раунд», затем финал и итоги.

## Кнопки на телефонах

Работают через [PeerJS](https://peerjs.com) (WebRTC): телефоны подключаются к ноутбуку ведущего напрямую.

- Публичный сервер PeerJS нужен только чтобы установить соединение.
- Первым считается нажатие, которое раньше дошло до ноутбука. Разница в сети измеряется десятками миллисекунд.
- Если обновить страницу у ведущего, нужно отсканировать новый QR-код.
- Нужен интернет на всех устройствах.

## Хранение данных

- **Где лежит пак:** в IndexedDB браузера. Картинки сжимаются до 1280 px (JPEG). Звук хранится как есть, до 10 МБ на файл, поэтому лучше загружать короткие отрывки.
- **Бэкап:** «Сохранить пак в файл» выгружает всё в один JSON вместе с картинками и звуком.
- **Если почистить данные браузера,** пак пропадёт. Храните JSON-копию.

## Структура

```
index.html   разметка экранов
style.css    стили
script.js    вся логика: редактор, игра, телефоны
```

## Внешние зависимости

Подключаются с CDN. Без интернета игра работает, просто без иконок, фирменных шрифтов и телефонов.

| Что | Лицензия |

| [PeerJS](https://peerjs.com) | MIT |
| [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) | MIT |
